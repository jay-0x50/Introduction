자기소개서

기능을 만들고, 직접 플레이하며 고칩니다.

구현한 기능이 화면과 조작에서 어떻게 느껴지는지 확인하며 게임을 개발해 왔습니다.

지원 동기

스크래치로 처음 프로그래밍을 접한 뒤, 오렌지보드로 자동 손 소독제를 만들어 학급에 기부했습니다. 코드를 작성한 결과가 사람의 행동으로 이어지는 과정이 재미있었습니다. 이후에는 입력에 따라 캐릭터가 움직이고, 판정과 피드백이 바로 돌아오는 게임 개발에 관심을 두게 됐습니다.

저는 게임을 플레이할 때 타격 판정이 어디에서 시작되고 UI가 어떤 값에 반응하는지 궁금해합니다. 궁금한 부분은 작은 프로토타입으로 만들어 보고, 플레이하면서 불편한 흐름을 다시 수정합니다.

프로젝트 경험

Exception에서는 플레이어 전투, 보스 HP와 Groggy, 체크포인트 저장, HUD 갱신을 C++로 구현했습니다. 근접 공격은 Sphere Sweep으로 판정하고, 같은 대상이 한 번의 공격에 여러 번 맞지 않도록 대상 목록을 따로 관리했습니다. HP가 바뀌면 Delegate를 통해 HUD가 갱신되도록 구성했습니다.

PyMax에서는 노트 데이터를 읽고 4키 입력을 판정해 콤보와 점수를 계산하는 흐름을 만들었습니다. 음악과 노트가 어긋나는 문제는 프레임 수 대신 시스템 시간을 기준으로 계산하도록 바꿨습니다. SpaceOut에서는 DirectX 11로 렌더링과 충돌 처리를 직접 구현했습니다.

협업과 목표

CodeUs 동아리 부장과 6인 팀 프로젝트의 메인 프로그래머를 맡았습니다. 제 기능을 끝낸 뒤에도 팀원의 오류를 함께 재현하고, 공용 로직이 충돌하지 않도록 작업 범위를 정리했습니다. 음성 인식 결과를 보스 전투 기믹에 연결할 때는 서버 응답과 보스 상태, UI 반응이 같은 흐름에서 작동하도록 맞췄습니다.

새로운 코드베이스에서는 먼저 실행 흐름과 수정 범위를 확인하겠습니다. 맡은 기능을 작은 단위로 구현하고 직접 플레이해 문제를 찾으며, 팀이 이어서 고치기 쉬운 코드로 남기는 게임 개발자가 되고 싶습니다.
