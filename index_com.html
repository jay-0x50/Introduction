자기소개서

만드는 즐거움에서, 쓰이는 소프트웨어로.

스크래치로 시작한 호기심을 프로그래밍 공부와 게임 제작으로 이어 온 박재영입니다.

성장 과정

초등학교 때 스크래치를 배우며 처음 프로그래밍을 접했습니다. 블록을 조합해 제가 생각한 동작을 만들어 볼 수 있다는 점이 재미있었고, 자연스럽게 코딩에 흥미를 갖게 되었습니다. 중학교에 올라가서는 SW동아리에서 파이썬을 배우며 블록 대신 직접 코드를 작성하는 즐거움을 알게 되었습니다.

프로그래밍 언어를 더 배우고 싶어 학원에 등록해 C언어 기초를 공부했습니다. 관심으로 시작한 공부를 직업으로 이어가고 싶었고, 소프트웨어를 전문적으로 배우며 취업을 준비하기 위해 미림마이스터고등학교에 진학했습니다. 스크래치에서 시작한 호기심은 새로운 언어를 배우고 직접 프로젝트를 만드는 원동력이 되었습니다.

배움을 활용한 경험

중학교 SW동아리에서는 코로나19 시기에 손 소독기를 만들어 학급에 배치했습니다. 프로그래밍으로 화면 속 결과를 만드는 것을 넘어, 교실에서 필요한 물건을 직접 만들어 본 경험이었습니다.

배운 기술이 주변 사람에게 도움이 될 수 있다는 점에서 보람을 느꼈습니다. 이 경험은 기능을 구현하는 것과 함께, 누가 어떤 상황에서 사용할지도 생각하는 계기가 되었습니다. 지금 게임을 만들 때도 직접 플레이하며 입력과 화면 반응을 확인하고, 사용하는 사람의 입장에서 어색한 부분을 고치려 합니다.

구현에서 배운 점

보스전 게임 Exception에서는 공격 판정뿐 아니라 전투 상태가 겹칠 때의 처리도 고민했습니다. 처형 중에는 그로기 회복을 미루고, 사망이나 페이즈 전환 중에는 회복 처리를 중단하도록 조건을 나눴습니다. 기능 하나를 만드는 것에서 나아가, 다른 기능과 이어질 때도 플레이 흐름이 유지되도록 생각하게 되었습니다.

리듬 게임 PyMax에서는 곡에 다시 진입할 때 이미지·음원이 이미 준비되어 있는데도 로딩 대기는 그대로 남아, 노래와 영상이 먼저 재생되는 문제가 있었습니다. 정해진 대기 시간 대신 리소스 로딩 완료를 재생 시작 조건으로 바꿨습니다. 이 경험을 통해 화면의 대기 시간과 실제 준비 상태를 구분하고, 처음 실행할 때뿐 아니라 재진입할 때도 확인해야 한다는 점을 배웠습니다.

협업과 피드백

CodeUs 동아리 부장과 6인 팀 프로젝트의 메인 프로그래머를 맡았습니다. Magic Girl Kawaii Lovelies에서는 보스 로직과 음성 입력 연동을 담당하고, 팀원의 오류를 함께 재현하며 공용 로직이 겹치는 부분은 작업 범위를 다시 나눴습니다.

교내에 게임을 배포한 뒤에는 플레이 피드백을 모아 조작과 진행 흐름을 수정했습니다. 제가 익숙해진 조작도 처음 플레이하는 사람에게는 다르게 느껴질 수 있었습니다. 이후에는 구현 여부뿐 아니라 플레이어가 다음 행동을 이해할 수 있는지도 함께 확인하려 합니다.

입사 후 포부

입사 후에는 팀의 코드 작성 방식과 게임의 플레이 흐름을 먼저 익히겠습니다. 맡은 기능은 입력부터 화면 반응까지 직접 플레이하며 확인하고, 수정 이유와 영향을 기록하겠습니다. 작은 기능도 끝까지 연결해 플레이어가 자연스럽게 조작할 수 있는 게임을 만드는 데 기여하겠습니다.
